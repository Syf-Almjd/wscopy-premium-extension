# ⚡ Simple WhatsApp Copier (PRO+ for free)

> A fast, elegant, 100% free and private browser extension that exports and copies WhatsApp Web chats.
>
> **Now featuring:**
> - 🖼️ **Tracked Images**: Images are tracked right where they occurred in the chat (rendered in HTML, referenced in Markdown, packaged in ZIP).
> - 🎙️ **Voice Note Transcriptions**: Automatically transcribes voice messages with disclaimer `⚠️ Voice Note Transcript (AI-generated from voice, may contain errors)`.
> - 📦 **ZIP Media Bundles**: Download chat + full `media/` folder in one click.
> - 🎯 **Ultra-Simple UI with "Advanced Options"**: Clean & instant for common tasks, with an expandable drawer for power users.
> - 🤖 **One-Click AI Copy**: Optimized for ChatGPT, Claude, Notion, and Obsidian.

## 🚀 How to Install in Google Chrome (10 Seconds)

1. Open **Google Chrome** (or Brave, Edge, Arc).
2. Go to `chrome://extensions` in the address bar.
3. Turn **ON** the **Developer mode** toggle in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select this directory:
   ```
   /Users/saifalmajd/saif/wa-copy/aqab
   ```
6. Open [WhatsApp Web](https://web.whatsapp.com) and click on any conversation.

## 💡 How It Works

1. **In-Chat Header Button:** Look at the top bar of any open chat; click the green **`[ ⚡ Copy Chat ]`** button.
2. **Floating Badge:** Or click **`⚡ Simple Copier PRO+`** in the bottom-right corner.
3. **Keyboard Shortcut:** Press `Alt + Shift + C` anytime.
4. **Clean Studio Modal:**
   - **One-Click AI Copy**: Instantly copies clean Markdown to clipboard ready to paste into ChatGPT or Claude.
   - **Range Selector**: Choose between *Visible*, *100*, *500*, *2,000*, or *Entire Chat*.
   - **Export Formats**:
     - **Markdown (`.md`)**: With tracked images and voice transcripts.
     - **HTML (`.html`)**: Beautiful offline viewer with dark/light mode, live search, and inline photos!
     - **PDF (`.pdf`)**: Formatted chat bubbles ready for clean document printing.
     - **ZIP (`.zip`)**: Packages the chat document along with all captured images and voice notes in a `/media` folder.
     - **Plain Text (`.txt`)**: Clean text log.
     - **CSV / Excel (`.csv`)**: Spreadsheet with columns for messages, media, and voice transcripts.
     - **JSON (`.json`)**: Raw structured developer data.
   - **Expandable "⚙️ Advanced Options" Drawer:**
     - Toggle image tracking and embedding.
     - Toggle voice note transcription.
     - Optional free Groq Whisper key for 100% automated AI voice note transcription.
     - Custom date range filter (From / To).
     - AI prompt templates (Summary, Action Items, Meeting Minutes).
     - Metadata toggles (Timestamps, Senders, Quoted replies, Reactions).
