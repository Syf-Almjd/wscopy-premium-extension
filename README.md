# ⚡ Simple WhatsApp Copier (PRO+ for free)

> A clean, fast, 100% free and private browser extension to copy and export WhatsApp Web chats.
>
> **100% Clean WhatsApp Web Experience:**
> No buttons or widgets injected into the WhatsApp interface. Everything is operated directly from your Chrome extension toolbar!

---

## 🌟 Key Features

- 🧹 **Clean WhatsApp UI:** Zero injected buttons on WhatsApp Web — controlled entirely from the extension icon.
- 📦 **Full ZIP Media Bundle:** Export a single `.zip` containing:
  - `chat.md` (Markdown with media links)
  - `chat.html` (Interactive offline viewer with dark/light mode & search)
  - `chat.txt` (Plain text log)
  - `media/image_1.jpg`, `media/image_2.jpg`, etc.
  - `media/voice_note_1.ogg`, etc.
  - `media/[documents]`
- 🎙️ **Voice Note Transcriptions:** Automatically transcribes voice notes and includes the warning:
  `⚠️ Voice Note Transcript (AI-generated from voice, may contain errors)`
- ⚙️ **All Options Inside the Popup:** Click **`⚙️ Full Options & Customization ▾`** right inside the extension popup to customize:
  - Images & media tracking
  - Voice transcription + optional free Whisper API key
  - Custom Date Range (From / To)
  - AI Prompt templates (Summarize, Action items, Meeting minutes, Custom)
  - Metadata toggles (Timestamps, Sender names, Quoted replies, Reactions)
  - Raw JSON export
- 📋 **One-Click AI Copy:** Instant clipboard copy ready for ChatGPT, Claude, Obsidian, and Notion.

## 🚀 How to Install / Reload in Chrome

1. Open **Google Chrome** (or Brave, Edge, Arc).
2. Go to `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. If already loaded: Click **↻ (Reload)** on `Simple WhatsApp Copier`.  
   If loading fresh: Click **Load unpacked** and select:
   ```
   /Users/user/Downloads/aqab
   ```
5. Open [WhatsApp Web](https://web.whatsapp.com), click on any conversation.
6. Click the **Simple WhatsApp Copier** icon in your Chrome toolbar to copy or export!
